# Regras permanentes para agentes

- Trabalhe incrementalmente e trate um problema por commit.
- Leia somente os arquivos necessários; não reanalise todo o repositório nas próximas fases.
- Preserve as funcionalidades existentes e não implemente mudanças fora da fase solicitada.
- Não invente evidências, resultados, comandos ou capacidades.
- Não exponha segredos, chaves, tokens nem conteúdo de configurações locais sensíveis.
- Testes não devem fazer chamadas externas; use mocks ou fallbacks determinísticos.
- Execute os testes relacionados após cada alteração.
- Atualize `docs/codex-state.md` ao concluir cada fase.
- Interrompa o trabalho assim que a fase solicitada estiver concluída.
